## Media Library

A full-stack solo project built to demonstrate a modern development and deployment architecture. The project is a media library focusing on CRUD operations, built with Laravel and orchestrated with Kubernetes.

## Tech Stack
- **Backend/Web:** PHP & Laravel
- **Frontend:** Node.js, NPM, Vite
- **Containerization:** Docker (Laravel Sail)
- **CI/CD Pipeline:** GitHub Actions
- **GitOps/Deployment:** ArgoCD
- **Infrastructure:** Kubernetes (Minikube / local testing)
